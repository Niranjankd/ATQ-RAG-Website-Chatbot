# ATQ - Any Time Questions

A RAG-powered website chatbot that allows users to enter a website URL, scrape website content, and ask questions based on the website information.

## Current Progress
- Streamlit UI completed
- Website URL input added
- Website scraping implemented using Requests and BeautifulSoup
- GitHub repository setup completed

## Technologies Used
- Python
- Streamlit
- Requests
- BeautifulSoup
- Git & GitHub
